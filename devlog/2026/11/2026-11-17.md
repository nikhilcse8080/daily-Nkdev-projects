# 2026-11-17 — Race-safe stock deduction with PDO transactions

**Stack:** PHP/MySQL · **Topic:** Inventory stock updates

When two billing counters sell the last brake pad at the same moment, a naive "read stock, then update" can push inventory negative. A conditional `UPDATE` inside a transaction makes the check and the deduction one atomic step.

```php
<?php
// Deducts stock for every line of an invoice, or nothing at all.
function deductStock(PDO $pdo, array $lines): void
{
    // $lines = [['part_id' => 101, 'qty' => 2], ...]
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    $stmt = $pdo->prepare(
        'UPDATE parts
            SET stock_qty = stock_qty - :qty
          WHERE id = :id AND stock_qty >= :min_qty'
    );

    $pdo->beginTransaction();
    try {
        foreach ($lines as $line) {
            $qty = (int) $line['qty'];
            $stmt->execute([
                ':qty'     => $qty,
                ':id'      => (int) $line['part_id'],
                ':min_qty' => $qty,
            ]);
            if ($stmt->rowCount() !== 1) {
                throw new RuntimeException("Insufficient stock for part {$line['part_id']}");
            }
        }
        $pdo->commit();
    } catch (Throwable $e) {
        $pdo->rollBack();
        throw $e;
    }
}
```

**Takeaway:** Put the stock check in the `WHERE` clause and test `rowCount()` — the database row lock does the race handling for you (InnoDB required).
