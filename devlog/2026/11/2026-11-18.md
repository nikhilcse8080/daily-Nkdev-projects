# 2026-11-18 — GST invoice totals with Decimal rounding

**Stack:** Python · **Topic:** Money math for billing

Floats drift (`0.1 + 0.2 != 0.3`), which breaks invoice totals in a billing app. Using `Decimal` with explicit half-up rounding per line keeps GST amounts matching what accountants expect.

```python
from decimal import Decimal, ROUND_HALF_UP

PAISA = Decimal("0.01")

def money(x) -> Decimal:
    return Decimal(str(x)).quantize(PAISA, rounding=ROUND_HALF_UP)

def invoice_totals(lines, intra_state=True):
    """lines: list of (qty, unit_price, gst_rate_percent)."""
    taxable = tax = Decimal("0")
    for qty, price, rate in lines:
        base = money(Decimal(str(qty)) * Decimal(str(price)))
        line_tax = money(base * Decimal(str(rate)) / 100)
        taxable += base
        tax += line_tax
    if intra_state:  # split equally into CGST + SGST
        cgst = money(tax / 2)
        split = {"cgst": cgst, "sgst": tax - cgst}
    else:
        split = {"igst": tax}
    return {"taxable": taxable, **split, "grand_total": taxable + tax}

if __name__ == "__main__":
    items = [(2, 349.50, 18), (1, 1299, 28), (4, 85.25, 12)]
    for k, v in invoice_totals(items).items():
        print(f"{k:>12}: {v}")
```

**Takeaway:** Never use floats for money — round each line with `Decimal` + `ROUND_HALF_UP`, then sum.
