# 2026-11-26 — Billing cart state with ChangeNotifier in paise

**Stack:** Flutter · **Topic:** State management for a POS/billing cart

A counter-sale screen for spare parts needs a cart that adds, decrements and totals items without float rounding drift. Storing money as integer paise in a `ChangeNotifier` keeps totals exact and lets any `ListenableBuilder` rebuild on change.

```dart
import 'package:flutter/foundation.dart';

class CartLine {
  final String sku;
  final String name;
  final int unitPaise; // ₹123.45 -> 12345
  int qty;
  CartLine(this.sku, this.name, this.unitPaise, [this.qty = 1]);
  int get totalPaise => unitPaise * qty;
}

class Cart extends ChangeNotifier {
  final Map<String, CartLine> _lines = {};

  List<CartLine> get lines => List.unmodifiable(_lines.values);
  int get itemCount => _lines.values.fold(0, (sum, l) => sum + l.qty);
  int get subtotalPaise => _lines.values.fold(0, (sum, l) => sum + l.totalPaise);

  /// GST in paise, rounded half-up per invoice (e.g. rateBps 1800 = 18%).
  int gstPaise(int rateBps) => (subtotalPaise * rateBps + 5000) ~/ 10000;

  void add(String sku, String name, int unitPaise) {
    _lines.update(sku, (l) => l..qty += 1,
        ifAbsent: () => CartLine(sku, name, unitPaise));
    notifyListeners();
  }

  void decrement(String sku) {
    final line = _lines[sku];
    if (line == null) return;
    if (--line.qty <= 0) _lines.remove(sku);
    notifyListeners();
  }

  static String rupees(int paise) =>
      '₹${paise ~/ 100}.${(paise % 100).toString().padLeft(2, '0')}';
}
```

**Takeaway:** Keep money as integer paise in your state class and format only at the edge — totals stay exact and the UI just listens.
