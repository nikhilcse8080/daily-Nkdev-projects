# 2026-11-16 — Debounced search input (vanilla JS)

**Stack:** JavaScript · **Topic:** performance / UX

Live-search boxes in billing and ERP screens fire a request on every keystroke.
Debouncing waits until the user stops typing before calling the API.

```js
function debounce(fn, delay = 300) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

const input = document.querySelector('#part-search');
const search = debounce(async (q) => {
  if (q.length < 2) return;
  const res = await fetch(`/api/parts?q=${encodeURIComponent(q)}`);
  render(await res.json());
}, 300);

input.addEventListener('input', (e) => search(e.target.value.trim()));
```

**Takeaway:** 10 keystrokes → 1 request. Use 250–400 ms for search boxes.
