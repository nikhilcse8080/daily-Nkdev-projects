# 2026-11-24 — Low-stock reorder report with CTEs

**Stack:** SQL · **Topic:** MySQL 8 CTEs for inventory reorder suggestions

For a two-wheeler parts counter, the buyer wants one list each morning: parts at or below their reorder level, ranked by how fast they sold in the last 30 days.
Two CTEs keep the stock and sales math readable, and `LEFT JOIN` makes sure parts with no movement yet still show up.

```sql
-- parts(id, sku, name, reorder_level)
-- stock_moves(part_id, qty, moved_at)   qty > 0 = purchase in, qty < 0 = sale out
WITH on_hand AS (
  SELECT part_id, SUM(qty) AS qty
  FROM stock_moves
  GROUP BY part_id
),
sold_30d AS (
  SELECT part_id, -SUM(qty) AS qty
  FROM stock_moves
  WHERE qty < 0
    AND moved_at >= CURRENT_DATE - INTERVAL 30 DAY
  GROUP BY part_id
)
SELECT p.sku,
       p.name,
       COALESCE(o.qty, 0)                       AS on_hand,
       COALESCE(s.qty, 0)                       AS sold_last_30d,
       p.reorder_level,
       p.reorder_level * 2 - COALESCE(o.qty, 0) AS suggested_order  -- refill to 2x reorder level
FROM parts p
LEFT JOIN on_hand  o ON o.part_id = p.id
LEFT JOIN sold_30d s ON s.part_id = p.id
WHERE COALESCE(o.qty, 0) <= p.reorder_level
ORDER BY sold_last_30d DESC, on_hand ASC;
```

**Takeaway:** Put each aggregate in its own CTE and `LEFT JOIN` them to the master table — you avoid double-counting from joining two many-row tables and never lose zero-stock parts.
